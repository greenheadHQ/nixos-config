# 이슈 본문 예시

대상 저장소의 관례에 맞춰 필요한 정보만 작성한다. 아래 예시는 고정 양식이 아니다.

## 작은 작업

```markdown
설정 파일을 생략하면 시작 명령이 실패합니다. 기본값으로 시작할 수 있도록 처리하고,
설정 파일 유무에 따른 시작 동작을 확인합니다.

근거: 관련 파일 또는 오류 기록 링크.
```

## 재현과 결정이 필요한 작업

```markdown
캐시가 만료된 직후 동시 요청이 오면 같은 데이터를 여러 번 조회합니다.

### 재현

캐시를 비운 테스트 환경에서 같은 키에 동시 요청을 보내면 원본 조회가 요청 수만큼 발생합니다.
기대 동작은 첫 조회 결과를 대기 중인 요청이 공유하는 것입니다.

### 제약과 완료 기준

실패한 조회가 캐시에 남아 후속 요청을 막아서는 안 됩니다.
성공·실패·서로 다른 키의 동시 요청을 확인해야 합니다.

근거: 현재 구현 경로와 관찰한 테스트 결과 링크.
```

비자명한 주장에는 확인한 근거를 연결한다. 아직 재현하지 못한 증상이나 선택하지 않은 대안은 그 상태를 명시한다. 파일 표·체크박스·CIR·ADR은 독자가 작업을 판단하는 데 도움이 될 때 추가한다.
