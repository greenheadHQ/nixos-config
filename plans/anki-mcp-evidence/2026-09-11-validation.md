# 개인용 Anki MCP 배포 후 검증 — 2026-09-11

## 현재 결론

#1315·#1316은 머지·MiniPC 적용 완료다. Anki 26.08·helper 2.0.0에서 ChatGPT 웹/iPhone, Codex, Claude의 인증된 실제 호출을 확인했다.
신규 이미지·음성의 AnkiMobile 표시·재생과 실패 시험 알림 수신도 사용자가 확인했다.
Mac 전원 종료 상태에서 iPhone 변경·AnkiMobile 표시·알림 수신을 확인했고, 운영 합성 노트·덱 정리까지 완료했다.

9월 9일 장시간 비교에서는 기존 카드 1장의 학습 상태와 복습 1건이 달라졌다. 추가 기록의 시각은 해당 시험 이전이었으며,
현재 복습 데이터에서 그 한 건만 제외한 메모리 사본의 해시가 원래 9,378건 기준과 일치했다. 기존 기록의 누락·변형은 없었다.
9월 11일 시험은 새 기준을 잡아 미디어 추가부터 최종 카드 정리까지 위의 변경 없음 결과를 확인했다. 서로 다른 시점의 카운트를 동일한 기준으로 섞지 않는다.

## 장애·복구 검증

- 저장소 격리 테스트: `nix develop --command bash tests/run-anki-mcp-tests.sh`, **178 passed**. 역할 인증·미리보기·root 일회 승인·미디어 대기·응답 유실·알림 결과 분리를 포함한다.
- 이전 실제 임시 Anki 컬렉션 API 시험 6개와 배포 후 `lab` 변경·복구점·재시작 중복 방지 검증은 #1315/#1316의 배포 기록을 따른다.
- 9월 11일 실제 미로그인 `lab`과 배포된 `OperationService`로 사전 sync 실패 시 변경 없음, 적용 응답 유실 후 같은 ID 조회/재개,
  사후 sync 시간 초과 후 전달만 재개, 알림 결과 불명 시 재발송 없음, 전달 영수증 응답 유실 복구, 같은 ID의 다른 payload 거부를 확인했다.
  helper와 카드 변경은 실제이며 sync/알림 전달 결과만 시험용으로 주입했다. 시험 노트·덱 삭제 후 기존 lab 데이터·덱 전체가 원래와 일치했다.
- 실제 Linux root와 HDD의 새 임시 디렉터리로 미러 해시·소유권·권한, 저장 대상 오류, 손상 ZIP 거부,
  영수증 쓰기 실패 시 기존 SSD 백업 보존 및 같은 작업의 미러 재개를 확인했다. 이번 시험 파일만 제거했다.
- 실제 sync 셸을 별도 상태 디렉터리와 가짜 helper 응답으로 실행했다. 네트워크 실패 분류, 같은 실패 24시간 중복 억제,
  정상 재개, `FULL_DOWNLOAD` 요구 시 방향을 선택하지 않고 중단, 상태 원본/사본·권한 일치를 확인했다.
  Pushover는 실패 시험 1건에만 실제 전송했으며 사용자가 `[검증] Anki 동기화 실패` 1개 수신을 확인했다.

실운영 AnkiWeb 장애·운영 HDD 분리·운영 프로세스 강제 종료·실제 학습 데이터 구조 변경·강제 Upload를 수행한 시험은 아니다.
완료 영수증의 `expires_at`은 준비 확인의 만료 시각이며 영수증 보관 기한으로 해석하지 않는다.
`NO_CHANGES`만으로 모든 기기 상태 일치를 주장하지 않는다.

## 완료 상태와 보존 결정

- Mac 전원 종료 실기기 시험, 작업 영수증·사전/사후 sync 대조, 미디어 표시·재생, 성공·실패 알림 수신을 완료했다.
- 운영 합성 노트 1개·카드 1개·빈 덱 1개를 삭제했다. 영향을 받은 복습 기록은 0건이다.
  각 삭제 전 root 복구점 생성·HDD 미러를 완료했고, 사후 파일의 소유권·권한·SHA256·ZIP 무결성을 확인했다.
  두 작업 모두 적용·normal sync·알림 전송이 성공했다. 최종 서버는 원래 노트 856개·카드 1,025개·복습 9,379건이며 테스트 노트·덱은 없다.
- 이 문서는 개인용 배포 검증의 완료 근거다. 이슈 상태는 마감 PR 머지 후 이 기록에 맞춰 갱신한다.
- **lab 유지**: 2026-09-11 사용자가 향후 시험용 유지를 선택했다. 서비스·실제 이력 사본을 유지하고, AnkiWeb 자격·sync를 활성화하지 않는다.
- 작업 영수증·검증된 HDD 복구점은 보존 대상이다. 미디어 삭제는 MCP 지원 범위 밖이므로 새 시험 PNG/WAV 2개(합계 9,981 B)는 미참조 파일로 남겼다. 기존 미디어는 변경·삭제하지 않았다.
- 개인 학습 규칙·AI 카드 관리 스킬·다중 사용자 연결/격리·공개 제품화와 제출·비용/사용량 정밀 측정은 별도 범위다.
  개인용 완료를 이유로 anki-study #3의 공개 확장 조건까지 완료 처리하지 않는다.
