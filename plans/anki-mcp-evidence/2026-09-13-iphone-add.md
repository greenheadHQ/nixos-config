# iPhone 직접 카드 추가 검증 — 2026-09-13

## 결론과 완료 기준

실제 iPhone의 ChatGPT에서 `anki_create_deck`과 `anki_add_notes`를 실행해 시험 덱 1개,
Basic 노트 1개·카드 1개를 생성했다. 작업 영수증과 별도의 서버 조회에서 ID·필드·태그가 일치했다.
AnkiMobile 카드 표시와 카드 추가 알림 수신을 요청한 뒤 사용자가 실제 확인했다고 답했다.
모바일 LLM의 응답은 서버 결과를 설명한 것이며, 기기 표시·수신의 근거는 사용자의 직접 확인이다.

사용자의 9월 13일 지시에 따라 iPhone 직접 추가를 필수 완료 조건으로 삼는다.
웹 카드 추가는 의도한 사용 경로가 아니므로 이번 완료 조건에 포함하지 않는다.
[9월 11일 기록](2026-09-11-validation.md)의 웹 추가와 iPhone 수정 결과는 당시 이력으로 보존하며,
그 조합으로 iPhone 직접 추가를 대체했던 완료 판단은 이 검증으로 정정한다.

## 서버 대조

아래 시각은 모두 2026-09-13 Asia/Seoul이다.

| 작업 | 적용 시각 | 확인 결과 |
|---|---|---|
| iPhone 덱 생성 | 12:30:22 | `applied`, normal sync 성공, 알림 `sent` |
| iPhone 노트 추가 | 12:30:33 | `applied`, 노트 1개·카드 1개 생성, normal sync 성공, 알림 `sent` |
| 독립 조회 | 생성 후 | Basic의 Front·Back, 요청 태그와 자동 `mcp::added`, 노트·카드 ID가 모바일 결과와 일치 |
| 시험 덱 정리 | 12:34:18 | Codex에서 preview 확인 후 삭제, 복구점/HDD 미러, normal sync·알림 발송 성공 |

세 변경 모두 journal과 작업 영수증을 대조했다. 사전 normal sync가 준비 전에 끝났고,
별개의 사후 normal sync가 적용 뒤 시작해 성공했다. `NO_CHANGES`만으로 기기 반영을 판단하지 않았다.
같은 작업의 고정 `request_id`를 사용했으며 카드 추가를 Codex나 웹에서 대신 실행하지 않았다.

## 정리와 데이터 보존

- 삭제 preview: 이번 시험 덱 1개, 노트 1개, 카드 1개, 복습 기록 0건. 대상 ID가 생성 결과와 일치했다.
- 삭제 전 SSD/HDD 복구점의 SHA256·ZIP 무결성과 root 영수증·권한을 사후 확인했다.
- 정리 후 시험 노트·덱이 없고, 기존 노트 856개·카드 1,025개·복습 9,379건이 남았다.
- 생성 전 기준과 생성 후·정리 후를 비교해 기존 노트·카드·복습 데이터 및 미디어 1,231개의 값/해시가 일치했다.
  미디어 수에는 9월 11일 보존한 시험 PNG/WAV 2개가 포함된다. 이번 시험에서 미디어 추가·삭제는 없었다.
- Lab 유지 결정과 기존 복구점 보존은 그대로다. 이번 삭제 복구점도 보존한다.

## 범위

iPhone 직접 추가, 별도의 서버 조회 대조와 AnkiMobile 반영·알림 수신을 확인했다. 앞선 iPhone 수정·Mac 종료 상태의 수정·미디어 시험은
9월 11일 기록을 따른다. 이번 정리 요청의 발신자는 Codex이며 iPhone 삭제 도구 검증으로 세지 않는다.
모든 변경 도구를 iPhone에서 전수 실행했다는 의미는 아니다. 실제 학습 데이터의 구조 변경·강제 Upload는 하지 않았다.
서버 동작 변경 없이 실기기 검증과 문서 정정만 수행했다.

개인 학습 스킬·규칙 및 다중 사용자 연결·공개 제품화는 별도 범위다.
원래 카드 내용·키·계정 정보가 섞일 수 있는 원본은 공개 문서에 첨부하지 않는다.
